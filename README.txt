Biblioteca do Dircksen

Autores:
- Lucas Dircksen

Descrição:
Site estático de uma biblioteca comunitária, com apresentação, destaque de livro, busca visual, categorias e catálogo de capas.

Como abrir a página:
1. Abra a pasta do projeto no computador.
2. Clique no arquivo index.html.
3. Ou use uma extensão como Live Server no VS Code para abrir em um navegador.

Fontes das imagens:
- As capas e ícones do projeto ficam na pasta img/.
- Os arquivos SVG e PNG usados no catálogo e no favicon foram criados/localizados para este projeto e estão armazenados localmente no repositório.
- A imagem destaque principal também está na pasta img/.

Observação:
Este projeto foi desenvolvido para funcionar diretamente como página estática sem necessidade de instalação de dependências.
