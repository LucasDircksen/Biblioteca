# Biblioteca do Dircksen

Site estático de uma biblioteca comunitária, criado para apresentar um acervo de livros em uma página simples, responsiva e em português.

## Sobre o projeto

A página apresenta o projeto **Acervo Livre** e reúne:

- Uma seção de apresentação da biblioteca;
- Um livro em destaque;
- Um campo de busca e categorias de leitura;
- Um catálogo com livros, autores e gêneros;
- Informações sobre a biblioteca e créditos no rodapé.

O campo de busca e os botões de categoria são elementos visuais no estado atual do projeto: ainda não filtram nem pesquisam os livros.

## Tecnologias

- HTML5
- CSS3

Não é necessário instalar dependências nem configurar um servidor para visualizar o site.

## Como executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` em um navegador.

Se preferir, use a extensão **Live Server** no Visual Studio Code para servir a página localmente.
